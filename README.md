# Explore Odisha — Modern & Luxury Tourism Portal

A modern, responsive luxury travel web application for **Explore Odisha**, built with **React JS**, **Tailwind CSS v4**, and **Lucide React**.

---

## ✨ Features & Architecture

### 1. Transparent Glassmorphism Navigation
- Dynamic scroll adaptation: sleek transparent hero overlay at the top, transitioning smoothly into a frosted glassmorphism bar with soft shadow and emerald accents.
- Live weather ticker (Puri, Daringbadi).
- Quick links for Destinations, Signature Trails, Cultural Heritage, and Trip Cost Calculator.
- Real-time Wishlist drawer toggle with badge counter.
- Mobile drawer navigation.

### 2. Full-Screen Cinematic Hero Section
- **Crossfading showcase** highlighting Odisha's diverse landscapes:
  - **Mountains & Peaks**: Deomali Peak (1,672 m) & Daringbadi ("Kashmir of Odisha")
  - **Untamed Waterfalls**: Barehipani (399 m) & Duduma (175 m)
  - **Pristine Beaches**: Golden Beach Puri (Blue Flag Certified) & Gopalpur-on-Sea
  - **Ancient Temples & Heritage**: Konark Sun Temple (UNESCO World Heritage) & Jagannath Dham
- **Large rounded floating search bar** with keyword search and district filter (Puri, Koraput, Mayurbhanj, Kandhamal, Ganjam, Khurda, Sundargarh).
- **Bold "Explore Now" button** with emerald-to-teal gradient, golden shimmer accent, and smooth scroll.
- **Interactive category chips**: Waterfalls 💦, Hills ⛰️, Temples 🛕, Beaches 🌊, Wildlife 🐅, Culture 🎭.

### 3. Metric Stats Banner
- Floating glassmorphism bar with high-impact figures: 485+ km coastline, 30+ waterfalls, 1,000+ temples, 62 indigenous tribes, and 4.9★ rating.

### 4. Trending Destination Cards
- Luxury cards with hover zoom photography, category badges, star ratings, district tags, and concise descriptions.
- Floating heart button for instant wishlist saving (persisted in `localStorage`).
- "Explore" trigger opening an in-depth modal.

### 5. Interactive Destination Detail Modal
- Multi-photo gallery preview.
- Quick fact indicators: Altitude, Best Visiting Season, Entry Fees, Nearest Transit Hubs.
- Detailed destination history and activity tags.
- Direct booking / inquiry request form simulation.

### 6. Curated Signature Trails & Cultural Showcase
- 3 signature multi-day itineraries: "The Golden Heritage & Spiritual Trail", "Highland Mist & Tribal Odyssey", and "Wild Biosphere & Coastal Lagoon".
- Cultural heritage section celebrating Pattachitra painting, Odissi classical dance, Chhena Poda cuisine, and Cuttack Tarakasi silver filigree.

### 7. Interactive Trip Cost Planner
- Real-time cost estimator based on travel style (Eco-Nature, Luxury Resort, Royal Heritage), duration (2-12 days), and traveler party size.

## 🎨 Color Palette & Typography
- **White / Alabaster**: `#ffffff`, `#fcfdfd`, `#f8fafc`

## 🚀 Getting Started

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Linting
```bash
npm run lint
```
